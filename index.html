Step 04
Root Cause: Ad Format Cannibalization
The new ad format wins more auctions but has a much lower CTR — cannibalizing old-format traffic and pulling down revenue.

BeforeOld80%4.12.00%0.082

Auction Insight: Score = Bid × pCTR. New format: 5.4 × 0.016 = 0.086 vs old: 4.1 × 0.020 = 0.082. Higher score wins more auctions — but actual CTR is only 0.9%. Old format win rate collapses 80% → 35%.
A
Why did the new format win more auctions?
Higher bid × pCTR score beats old format
▾

Winner = highest Score = Bid × pCTR. New format: 5.4 × 0.016 = 0.0864. Old format: 4.1 × 0.020 = 0.0820. New format wins ~60% of auctions; old format collapses to 35% win rate.

New Score: 5.4 × 0.016 = 0.0864
Old Score: 4.1 × 0.020 = 0.0820
B
Why is actual CTR so much lower?
pCTR model is miscalibrated — overestimates click probability
▾

New format pCTR used in auction (1.60%) is much higher than actual CTR (0.90%). The model overestimates. If pCTR = actual CTR: 5.4 × 0.009 = 0.049 — far below old format 0.082. The new format would lose most auctions.

This calibration gap is the core technical root cause. Fix: retrain pCTR model with real click feedback from the new format.
C
Why didn't higher CPC save revenue?
Higher CPC × far fewer clicks = net revenue loss
▾

Per 100,000 impressions:

Old format: 100K × 2.00% × $3.80 = $7,600
New format: 100K × 0.90% × $4.80 = $4,320
Net loss per 100K impressions: −$3,280 (−43%)

CPC is not the right north star. Revenue per Mille (RPM) is the correct metric — it captures both dimensions.

Step 05
Building Causal Inference
Correlation ≠ causation. Use a rigorous framework to attribute revenue decline to the new ad format.
Establish Temporal Order
Confirm new format launch preceded the revenue drop. Find the inflection point in time-series data.
Check for Confounders
Seasonality, competitor activity, advertiser budget changes, algorithm updates? Rule out by slicing by country, surface, and user cohort.
Segment Analysis: Unaffected Surfaces
Find surfaces where the new format was NOT launched. Do they show the same drop? If not, new format is the likely cause.
A/B Test / Holdout Analysis
Identify a holdout group — users who only saw the old format. Compare revenue-per-impression to the treatment group for the cleanest causal estimate.
Difference-in-Differences (DiD)
Compare revenue trajectory of surfaces that got the new format vs those that did not, before and after launch. DiD isolates the causal effect.
Quantify the Effect
Estimate: what would revenue have been without the new format? Attributable impact ≈ −$2,348 (−31%) in this case.
Causal Chain: New format launch → Wins more auctions (higher score) → Old format loses impressions (80% → 35% win rate) → New format has much lower actual CTR (0.9% vs 2.0%) → Clicks drop (2,000 → 1,240) → Revenue declines ($7,600 → $5,252).
Step 06
Recommended Actions
With root cause established, what levers can the team pull?
🎯
Recalibrate pCTR Model
New format pCTR (1.6%) overestimates actual CTR (0.9%). Retrain with real click feedback so auction scores reflect true engagement.
⚖️
Apply Format Discount
Introduce a quality-adjusted score discount for new formats during calibration, or set a minimum CTR threshold for auction eligibility.
🧪
Improve Format Quality
Work with design/product to improve UX. A/B test creatives, placements, and targeting to close the pCTR vs actual CTR gap.
📊
Use RPM as North Star
Adopt Revenue per Mille (RPM) as primary auction health metric. Captures both CPC and CTR; prevents format-mixing distortions.
🌎
Staged Rollout
Limit new format to surfaces where it performs better. Use holdout groups to gather causal evidence before broader deployment.
🔔
Revenue Guardrails
Automated alerts for RPM drops >5% during any new format launch. Gate full rollouts on passing a revenue-neutral threshold.
Step 07
Verify Impact of Actions
Every fix needs a measurement plan. How do we know actions worked and caused no side effects?
1
Define Primary and Guardrail Metrics
What to optimize, and what must not regress
▾

Primary Metrics

  • Total Ad Revenue ($)
  • RPM (Revenue / 1,000 impressions)
  • Effective CTR (blended)

Guardrail Metrics

  • Advertiser ROI
  • User experience signals
  • Total impressions served
2
Run a Holdout A/B Test
Controlled experiment to measure the fix's causal impact
▾
  • Control: Old system (overestimated pCTR)
  • Treatment: New system (recalibrated pCTR)
  • Run for at least 2 weeks; measure RPM, CTR, Revenue
  • Check statistical significance (p < 0.05)
3
Monitor Post-Launch Dashboards
Watch metrics day-over-day after full rollout
▾
  • Daily RPM by surface and ad format
  • Win rate rebalance: old vs new format
  • pCTR vs actual CTR ratio per format (target: converge to 1.0)
  • Revenue anomaly alerts if drop >5%
Success: old format win rate recovers to ~60–70%, effective CTR returns to ~1.8–2.0%, revenue recovers within 2–3 weeks.
